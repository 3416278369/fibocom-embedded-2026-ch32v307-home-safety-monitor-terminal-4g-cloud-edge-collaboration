## 📖 作品简介
本作品面向智能养老社区，设计养老环境与健康监护智能系统，依托嵌入式技术缓解养老监护人力短缺问题。系统集成多传感器，实时采集环境数据，监测老人心率、血氧，搭载摔倒检测功能，发生摔倒可自动电话告警，支持语音或手动取消呼叫。 系统可管控照明、风扇、模拟窗户、空调等设备，支持触屏、语音、华为云远程及自动联动控制，可自定义阈值实现环境设备联动，火焰险情自动开窗并报警。 系统支持语音 / 触屏拨号，具备语音查时、状态播报等功能。基于华为云可远程查看监测数据与终端位置，构建 “多源感知 — 智能联动 — 应急告警 — 云端管控” 监护闭环，为老人提供全天候健康监测、环境调控与应急防护，助力普惠智能养老落地社区家庭。

## 🧠 核心功能
功能点 1：多传感器数据监测，可采集温湿度、空气质量、土壤湿度、光照、火焰、心率、血氧，支持摔倒检测；检测摔倒后自动拨打电话，支持语音或手动取消呼叫。
功能点 2：多方式设备控制，可操控照明灯、风扇、水泵、模拟窗户、红外空调；支持触屏、语音、华为云远程、自动阈值控制，各类传感器阈值可自定义，环境恢复后设备自动关闭，火焰触发开窗与电话拨打。
功能点 3：电话相关功能，支持触屏、语音拨打联系人电话，可编辑联系人号码；附带语音查时间、屏幕展示设备状态、通话语音播报，华为云可查看监测数据与芯片地理位置。
